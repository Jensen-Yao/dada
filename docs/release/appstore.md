## 2. 应用描述（5 段式，共约 480 字，上限 4000）

**① 一句话定位（约 40 字）**

> 搭搭是专注「找搭子」的轻社交平台：发一个搭局，找到同好一起吃饭、自习、运动、旅行、看展，万物皆可搭，找人别犯难。

**② 核心功能（约 130 字）**

> 【发布搭局】14 类场景、时间地点人数、AA 方式、性别要求，一分钟组一个局。【智能发现】同城筛选、热门排序、「为你推荐」基于兴趣标签和历史参加记录。【组局审批】申请加入、组局者审批、满员自动关闭。【站内聊天】实时消息、首条安全提示。【搭后互评】星级+标签词互评，沉淀你的公开搭子履历。

**③ 场景化卖点（约 140 字）**

> 周末想看展没人陪？发一个「周六看展搭」。自习总犯困？找个图书馆学习搭互相监督。演唱会抢到票缺同伴？同城搭友一键报名。提前体验新店、拼车出游、夜跑健身、剧本杀缺人——每个搭局都写清时间地点人数与费用方式，报名前一目了然，不用再在群里「有人吗」刷屏。

**④ 安全承诺（约 120 字）**

> 我们认真对待每一段搭子关系：涉黄暗语与导流话术自动拦截，违规内容人工审核；私信需先同局才能发起；「仅限女生」搭局强制校验性别；SOS 紧急求助直达平台管理员；搭力值信用体系让靠谱的人被看见，累计 3 次违规自动封号。

**⑤ 行动号召（约 50 字）**

> 别再一个人吃饭、一个人自习、一个人旅行了。现在下载搭搭，发你的第一个搭局，找到那个「刚好也想」的人。

## 5. 年龄分级问卷（如实作答 + 保守策略）

| 问卷项 | 答案 | 说明 |
|---|---|---|
| 卡通/幻想暴力 | 无 | |
| 现实暴力 | 无 | |
| 性内容与裸露 | 无 | 有 UGC，见下 |
| 色情/成人主题 | 无 | |
| 冒犯性言语（低俗幽默） | 无 | |
| 受管制物质（烟酒药物） | 无 | |
| 赌博（含模拟） | 无 | |
| **用户生成内容（UGC）** | **是** | 搭局/评价/聊天均为 UGC |
| UGC 内容过滤 | 是 | 敏感词与涉黄暗语词库自动拦截（server/src/util.js filterContent） |
| UGC 举报机制 | 是 | 每条搭局/用户/消息可举报，管理员后台处理（警告/封禁/下架/驳回） |
| UGC 24 小时内响应审核 | 是 | 举报进管理员队列 + 通知推送；上线前需安排值班响应 |
| 不受限网页访问 | 否 | WebView 仅加载自有域名 dada.example.com |
| 年龄分级结果 | **17+** | UGC 陌生人社交 + 线下见面场景，按「可能包含用户生成的不当内容」如实作答会得出 17+；不要为过审虚报 4+/12+，被复查发现将下架 |

17+ 的运营应对（审核备注中也要写）：
1. 发布与聊天敏感词过滤（涉黄暗语、导流、涉诈话术三类词库）；
2. 举报→管理员队列→警告/封禁/下架的闭环，且封禁有累计 3 次自动封号策略；
3. 14 岁以下不可用的年龄门槛声明（见隐私政策未成年人条款）；
4. 女性保护：仅限女生局性别强校验、SOS 直达管理员、一键拉黑。

```

普通用户：xiaoyu / 123456（已认证，有搭局与评价数据）
管理员：admin / 123456（运营后台：数据看板、举报队列、用户管理）
也可直接注册新账号，注册即展示《用户协议》与《隐私政策》入口。

【建议测试路径】
1. 登录 xiaoyu → 首页广场浏览搭局（游客也可浏览）。
2. 打开任一搭局详情 → 查看轮播图、申请加入、评论区。
3. 「消息」→ 查看站内聊天（首条消息自动附带安全提示）。
4. 「我的」→ 搭力值（信用分）、搭子履历 → 「安全中心」查看社区公约与 SOS。
5. 切换 admin → 运营后台 → 举报队列：可对举报执行警告/封禁/下架/驳回。

【UGC 审核机制说明】
- 发布与聊天内容经敏感词库自动过滤（涉黄暗语、站外导流、诈骗话术）；
- 全部内容支持举报，管理员后台处理并通知双方；
- 违规阶梯：警告 → 累计 3 次自动封号；搭力值 < 300 禁止发布；
- 14 岁以下儿童不可注册（见隐私政策「未成年人保护」）。

【其他】
- 本 App 为 WebView 加载自有站点，不包含不受限网页访问；
- 应用内不发生任何资金交易，无内购，无广告；
- 隐私政策：https://dada.example.com/#/legal/privacy（占位，提交前替换为正式域名）
- 联系人：__姓名__（占位） / __电话__（占位）
```
