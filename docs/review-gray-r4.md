# R4 灰产对抗评审（风控对抗方向）

角色：模拟职业灰产团伙（引流党 / 酒托变体 / 职业组局党 / 刷子）对 v2.9/3.0 服务端做实战攻击。
方法：全新种子库 + 本地起服（:3968），curl + node/ws 客户端真实执行全部剧本，21 个灰产账号、约 150 个请求，全程约 20 分钟（攻击流量合计 < 2 分钟）。
基线防护（已知，不重复计分）：JWT 文件密钥、限流矩阵（sms 10/IP/h、login 20/15min、WS 5帧/秒/连接 + 单用户5连接）、举报 24h 去重、敏感词表、私信 approved 门槛、for-you 性别过滤。

## R4灰产对抗：10条攻击路径（8 成功 / 1 部分成功 / 1 被拦）

**总战果：27 条灰产帖（引流 13 + 收费 3 + 色粉变体 12 − 重叠）在广场公开存活 12+ 分钟零处置；受害者 for-you 第 1~4 位被灰产局包揽；同城热榜第 1 位是收费局。**

---

### [G1-a] 引流话术发帖 —— 成功
- **步骤**：注册 10 个号（用户名模式，每号 1 请求，无手机号无验证码）→ 每号发一条"正常徒步局"，正文内嵌引流变体。
- **结果（存活 N 条 / N 分钟）**：**8/10 首轮直接发布成功**，存活 12+ 分钟无任何自动处置（定时任务只做过期，无巡检）。命中拦截的只有词表原文 `vx:abc`、`加V：`。
- **变体实测**：`细节私聊我`✅ `V我`✅ `威❤️：abc`✅ `用微小的信找我`✅ `薇❤：abc`✅ `威 信`（空格拆字）✅ `➕V❤`✅ `联系方式看主页签名`✅；仅 `vx:abc`❌ `加V：`❌。
- **现有防线缺口**：`util.js SENSITIVE_WORDS` 约 50 个整词、`includes` 精确匹配，无归一化（分隔符/零宽/emoji/全半角/拼音）、无模式规则（"变体字+连续账号串"）、无图片 OCR/二维码检测。
- **建议防线**：
  1. 过滤前先归一化：去空白与零宽字符、emoji 剥离、全半角统一、保留小写副本再匹配；
  2. 增加正则模式而非整词：`(微|威|薇|V|v|❤|➕|+\d){1,3}[信❤:：\-]?\s*[a-zA-Z0-9_-]{5,20}`、手机号 `1[3-9]\d{9}`、`细节|私聊|主页|签名.*(方式|联系)`组合评分制（单命中进审核，多命中直接拒）；
  3. 内容命中进入"先审后露"队列（新号前 N 帖强制），而不是只靠事后举报。

### [G1-b] 未设防资料字段（昵称/签名/学校/职业/标签/地点）—— 成功（最严重缺口）
- **步骤**：用**已被内容侧拉黑的原词** `vx:abc2026` 逐字段打。
- **结果**：
  | 字段 | 结果 |
  |---|---|
  | post.title / content / requirements / 申请留言 / 评论 | 拦截 ✅ |
  | **post.location_name** | **原文入库并公开展示**（"西湖边上 vx:abc2026"） |
  | **nickname** | **"薇❤abc2026" 通过，且作为作者名在广场 feed 每帖曝光** |
  | **bio** | 原文通过，游客可见 |
  | **school**（PUT /me 与学生认证两处） | 原文通过，且**学生认证徽章 +30 分直接下发**（"vx:abc2026中学"成了已认证学校） |
  | **occupation** | "加V看主页" 通过 |
  | **tags** | `["vx","加V","薇信"]` 通过，进入 for-you 标签匹配权重 |
- **现有防线缺口**：`filterContent` 只覆盖帖文/评论/申请/聊天；`PUT /users/me` 的 7 个字段、学生认证 school、帖子 location_name 全部裸奔。灰产把"被拦后改图片"的问题直接绕过了——**账号资料本身就是广告牌**。
- **建议防线**：所有用户可控文本字段（昵称/签名/学校/职业/标签/地点/认证学校）走同一个 `filterContent` 管道；资料字段命中不 400 而是"落库打标 + 进审核 + 前端置灰"，因为存量脏数据需要回扫。

### [G1-c] 图片通道（被拦后改图片）—— 成功
- **步骤**：文字被拦后，向帖子和头像上传任意 PNG（实际场景即微信二维码截图）。
- **结果**：`POST /posts/:id/images` 与 `POST /users/me/avatar` 均接受（仅校验 mimetype/大小），无 OCR、无二维码解码、无hashed黑名单；游客立即可见 `/uploads/...`。
- **现有防线缺口**：图片零审核。聊天虽不支持图片，但帖子配图 + 头像是完全等效的引流位。
- **建议防线**：接入二维码检测（zxing 类库解码，命中即拒）、轻量 OCR（命中"微信/加V/VX"即拒）、上传图片 perms 下发前打审核态；同一图片 hash 复用检测（批量团伙常用同一张码图）。

### [G1-d] 聊天通道"打码照发" —— 部分成功
- **步骤**：WS 发 `vx:abc2026`、`加微信吧123456`、`威❤abc2026`、`纯/绿可以聊吗`。
- **结果**：词表命中词被打码成 `**:abc2026`、`***吧123456` 后**照常入库投递**——真正的联系方式载荷（`abc2026`、`123456`）完好存活；未命中词表的所有变体 100% 原文直达。即打码策略只遮住"触发词"不遮"payload"，灰产改写触发词即全量通过。
- **现有防线缺口**：`handleChatMessage` 只替换不拦截、不计数、无升级（warnUser 从未在聊天路径被触发）；私信 approved 门槛挡不住"组局后私聊"这一灰产主路径。
- **建议防线**：聊天命中即拒收（不是打码）+ 按用户累计计数（1 次警告、3 次 `warnUser`、5 次禁言私信）；打码后仍包含 5+ 位连续字母数字串的二次校验；收信方侧举报消息后自动对该会话取证。

### [G2-a] 职业组局党收费话术 —— 成功
- **步骤**：发"高端局"帖收组织费。
- **结果**：`每人收组织费99元…先转组织费锁位`✅发布；`每位服务费99，定金锁位`✅发布；`高端商务宴请女性搭档，全程买单另有酬劳`✅发布（还挂上了"仅限女生"）。仅词表原文 `费用全包`❌。
- **现有防线缺口**：fee_mode 只有 free/aa/treat 展示语义，服务端不校验文本中的收费表述；`转账/汇款` 在词表但"转定金/锁位/组织费/服务费/酬劳"不在。
- **建议防线**：词表补 `组织费|服务费|定金|锁位|报名费|酬劳|报酬|收费|付费`；规则：fee_mode='free' 且文本含费用词 → 拒；含收费词的帖对新号先审后露；`仅限女生` + 新号 + 无历史 → 进人工审核队列（酒托标准前置特征）。

### [G2-b] 互刷搭力值 + 老搭子加权 → for-you / 热榜霸屏 —— 成功（平台级风险）
- **步骤**：① 两号循环"发局→小号申请→通过→标记完成→互评5星"；② 给受害者画像（杭州/徒步/美食/INFP）后观测 for-you；③ 10 个小号点赞+刷评。
- **结果**：
  - 刷分：**9 请求/轮 ≈ 370ms，双方各 +30 搭力值 + 老搭子 times+1**；3 轮 27 请求后 600→690，14 轮即摸到 1000 上限。全程无任何频控/关系熵检测。
  - for-you 霸屏：刷分 + 克隆受害者标签后，灰产 4 条帖（含收费局）**包揽受害者 for-you 第 1~4 位**（score 92，理由"共同兴趣/同城/高信用搭友"），对照组正常帖第 14 位。
  - 老搭子固化：诱导受害者完成 1 次真实同局后，灰产新帖 score **100**、"老搭子·搭过1次"理由**永久 #1**，且触发"老搭子新局"站内推送——灰产获得对受害者的**免费定向推送通道**。
  - 热榜：10 赞 + 10 条"已报名期待"评论（20 请求，评论内容全部过审）→ 收费局**同城热榜 #1**；`/recommend` 同公式同洞。
- **现有防线缺口**：互评加分无同防（同 IP/设备簇互评照加）；partners.times 无真实性校验；credit 直接进 for-you 权重（`高信用搭友`）而 credit 可被脚本量产；like/comment 无每日频控无质量过滤。
- **建议防线**：
  1. 互评加分加 72h 延迟生效 + "同局需 ≥3 名参与者或双方各有 ≥3 个非重叠搭友"才计分；
  2. 同 IP/同设备指纹簇的账号互评不计分、不累计 partners.times（聚合 `joins`+`reports`+注册元数据做簇识别）；
  3. like/comment 每用户每日每帖 1 次（like 已是唯一约束，但无每日总量上限）、新号（<7 天）互动权重减半；
  4. for-you 的 credit 权重改用"不可刷分"（认证分）或引入新号降权。

### [G3-a] 色粉暗语变体 —— 成功
- **步骤**：16 个变体发帖 + 3 条变体走 WS 私信。
- **结果**：仅词表原文 `纯绿/可约/线下有偿/有偿陪` 被拦（拦截率 25%）。**发布成功 12 个**：`纯/绿`、`纯 绿`、`绿色发展主题`、`绿色出行陪伴`、`绿色结识`、`chunlv`、`纯lv`、`yuepao`、`yp529`、`找pao友`、`一夜缘`、`企鹅号送福利`。私信侧变体原文直达，`chunlv，有偿陪逛` 仅打码为 `chunlv，***逛` 照发。
- **现有防线缺口**：同 G1-a——整词精确匹配无分隔符/拼音/同音归一化；拼音词表为空。
- **建议防线**：归一化后匹配 + 拼音转换匹配（chunlv/chun lv/純綠繁体）+ 拆字组合评分（"纯"+"绿" 共现、"绿色"+地点+女性指向组合即拦）；聊天侧同 G1-d 拒收+计数。

### [G3-b] 性别自申报绕过"女生局" —— 成功（女性安全直接相关）
- **步骤**：男号注册时 gender=female（纯自申报，无任何核验）→ ① 申请他人女生局（通过）；② 自建"女生专属下午茶局"钓真实女性，受害者加入后私信门槛即达成，钓鱼话术送达。
- **结果**：申报 female 的男号加入女生局返回 pending（组局者按资料放行即入局）；假女生局全链路跑通，真实女性账号收到"高端局，女生免费"私信（仅"女生免费"被打码）。**性别是整个平台唯一的身份自申报字段。**
- **现有防线缺口**：`gender_req` 过滤只是把问题挡在 join 一层，gender 本身零核验；"新号 + 仅限女生 + 无历史"无审核。
- **建议防线**：女生局的**发布者**与**加入者**要求真人认证（人脸/运营商三要素）后才允许 gender=female；新号 72h 内发布的 gender_req=female 局进审核；申报性别与行为画像冲突（如被 3 人举报性别不符）自动转人工。

### [G4-a] 认证分无限刷（用户名注册 / 注销重注册）—— 成功
- **步骤**：① 用户名模式注册（无手机号！1 请求/号）→ 真人认证 +50 → 学生认证 +30；② 手机号注册 → 认证 → 注销 → 同号重注册 → 再认证。
- **结果**：
  - **用户名注册完全绕过手机号实名**：3 请求/240ms 得到一个 credit 680、带双认证徽章的"可信"账号。认证材料是自由文本（"随便写的大学"过审）。
  - **同一手机号 13800001234 实测两连刷**：第 1 个账号 +50 后注销；同号重注册的新账号再领 +50+30=+80。真人认证分按"账号"发而非按"人/证件"，注销即重置。唯一刹车是 sms 10/IP/h（代理池/接码平台秒破）。
- **现有防线缺口**：用户名模式是面向公网的无门槛注册后门（"存量测试兼容保留"）；verify 无材料校验无设备维度去重；注销清零认证状态使"真人"成为可再生资源。
- **建议防线**：用户名注册默认 `verify_*` 不可用且 credit 上限压到 300 以下（不能发帖），或干脆仅保留在测试构建；真人认证绑定设备指纹 + 手机号维度只发一次（注销后同号/同设备重注册不再发放认证分）；认证分（verify 加成分）与可刷分（互评/完成分）分开建模。

### [G4-b] 举报自己小号触发 dismiss 返还循环 —— 被拦（+一个残余向量）
- **步骤**：alt2 举报 boss1（-20）→ admin dismiss（+20）→ 换 alt1 同日再举报。
- **结果**：**循环净收益为 0**，不是刷分路径（同日多举报者只扣一次、24h reporter-target 去重、dismiss 精确返还 +20，三道防线均验证有效）。但残留向量：**首次举报的 -20 即时生效、零材料、零成本**——灰产可用它秒扣竞争对手/普通用户 20 分（每人每日每目标一次），用户侧无感知申诉入口。
- **建议防线**：-20 改为"举报受理进入人工队列即冻结信用（不可用不扣除），核实成立才真扣"；或首次举报只打标不扣分，累计 ≥3 个独立举报人再扣。

## 防住剧本
- **[G4-b] 举报刷分循环**：24h 去重 + 同日同目标只扣一次 + dismiss 精确返还，完整闭环，净收益 0。
- **[G1 局部] 帖子 title/content/requirements、评论、申请留言**的词表原文拦截有效（但仅限原文）。
- **[G2 局部] fee_mode/性别枚举校验、加入自己局拦截、互评"同局才可评"约束**均有效，灰产无法凭空互评，必须真实走完组局流（但也只花 9 个请求）。
- **限流矩阵本身**：sms/login/WS 窗口工作正常（本次攻击未触发，因用户名注册根本不走这些通道——这恰是问题所在）。
- **满员自动婉拒、拉黑联动通知过滤**等常规边界处理无破绽。

## 灰产成本结论：当前平台对灰产的吸引力评估

**吸引力：高（接近"不设防"）。**

实测单位成本（单操作者、一台机器、20 分钟）：

| 动作 | 成本 | 产出 |
|---|---|---|
| 一个"可信"账号（注册+双认证） | **3 请求 / 0.24s / 0 元** | credit 680 + 真人&学生徽章（进 for-you"高信用搭友"权重） |
| 一条存活引流帖 | 2 请求 | 12+ 分钟零处置存活，实际存活期 = 直到被人工举报 |
| +30 搭力值/号 + 老搭子关系 | 9 请求 / 0.37s | 通往 for-you #1 的权重 |
| 受害者 for-you 第 1~4 位 | ~60 请求 | 含收费局；老搭子固化后永久 #1 + 免费定向推送 |
| 同城热榜 #1 | 20 请求（10赞+10评） | 收费局登顶 |
| 钓到真实女性私聊 | 1 个假女生局 + 通过申请 | 私信门槛（approved）被组局行为本身解锁 |

结构性结论：
1. **最大单点不是词表，是"零成本账号"**：用户名注册后门让 sms 10/IP/h、login 20/15min 两道限流对灰产**完全失效**（根本不经过）。注册后默认 credit=600 ≥ 300 门槛，新号即刻可发帖、组局、解锁私信。
2. **防御是"词表 + 举报"的被动模型**：无先审后露、无自动化巡检、无图片审核、无账号图谱。灰产存活时间下限 = 平台人工处理时长，而平台没有任何加速发现灰产的信号（引流变体不触发任何计数）。
3. **推荐系统可被量产信号购买**：credit、tags、partners.times、likes 全部可脚本量产且直接进 for-you/hot 权重——灰产不仅能曝光，还能**精准霸占目标人群的推荐位**，这是对普通用户体验和平台信任的长期污染。
4. **"真实性"资产（认证徽章、搭力值、好评）正在通胀**：徽章=自由文本、信用=9 请求/30 分、好评=互刷。平台安全提示还在引导用户"信任搭力值与评价"——等于把用户导向灰产伪造的信号。

**优先级整改（Top 3）**：
1. **关死零成本账号**：用户名注册收缩到测试构建；线上账号必须手机号 + 新号 credit<300（不可发帖）+ 注册后 24h 内发帖先审后露 + 同 IP/设备每日注册配额。
2. **统一内容管道 + 拒收制**：全部用户文本字段（含昵称/签名/学校/职业/标签/地点/认证学校）过归一化 filter（分隔符/零宽/emoji/全半角/拼音）；聊天从"打码照发"改"命中拒收 + 用户计数升级"；图片接二维码/OCR 检测。
3. **反 manipulation 的信任分**：互评加分 72h 延迟 + 同簇账号（同 IP/设备指纹）互评不计分；partners.times 与 for-you 老搭子加权要求"非簇内关系"；认证分同号/同设备只发一次，注销不重置；被举报 -20 改为冻结制。
